# Task Board (Vue 3)

Trello uslubidagi vazifalar doskasi. [amaliyot_tasks](https://github.com/mjavohir06/amaliyot_tasks) (Next.js) loyihasining Vue 3 versiyasi.

**Demo:** https://amaliyot-taks-vue-ts.vercel.app

**Texnologiyalar:** Vue 3, TypeScript, Vite, lucide

## Imkoniyatlar
- Ustunlar va vazifa kartalari, vazifa tafsilotlari oynasi
- Teglar (label), mas'ul shaxs, muddat tanlash
- Filtrlash paneli, loyihalar orasida almashish

## Ishga tushirish

```bash
npm install
npm run dev
```
